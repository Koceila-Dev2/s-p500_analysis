# S&P500 Analysis — Dashboard Exoplanètes

Dashboard Streamlit qui montre en quoi le catalogue d'exoplanètes connu est biaisé par les méthodes de détection utilisées, plutôt qu'un simple état des lieux des planètes découvertes.

## Lancer le dashboard

```bash
cd dashboard
pip install -r requirements.txt
streamlit run dashboard.py
```

Le dashboard est ensuite accessible sur [http://localhost:8501](http://localhost:8501).
